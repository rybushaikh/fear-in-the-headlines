# Requesting the data

The cleaned data isn't public. It's shared case by case, with the author's permission.

| Data | Available on request? |
|---|---|
| ABC and HuffPost headline text, cleaned | Yes, subject to each dataset's own licence |
| Fear scores, levels and subjects, linked to article IDs where an ID exists | Yes |
| Labels on the fear scale, linked to article IDs where an ID exists | Yes |
| NYT and Guardian headline text | No. Re-fetch it with your own API keys using `pipeline/` |

**How to ask:** open a [data request](https://github.com/rybushaikh/fear-in-the-headlines/issues/new?template=data-request.yml). Issues are public, so don't include private information.

**If your request is approved**, you agree to use the data only for the purpose you described, not to pass it on without permission, and to credit this project in anything you publish. Requests may be declined, and approval may take time.
