# PLAN v12: v7f, more current data, fix 1s cheaply, 2–3s stay the focus (frozen 27 Oct 2026, before computing)

## Why
v7e (live) on sealed #4: κ .93, exact 81%, 2–3s caught 94%, but true 1s only about half right (20/42; 12 called 2), and false alarms on tricky calm 17%. It was trained and tested only on 2003–21 text. The user wants more and current data, 1s good enough not to be mistaken for 2s, without an expensive 1s effort; 2–3s remain the priority.

## Data (collected 27 Oct)
- NYT Archive 2022-01 … 2026-10 (`recent_fetch.py` → `abc_all/recent_nyt.parquet`); Guardian 2022–26, random day per month + 10 threat tags (2–3 days, API cap).
- HuffPost News Category (210k, 2012–22, CC-BY-4.0) at `data/external/huffpost/`, for the subject classifier only (not fear).
- Media Cloud: waits for the user's key.
- **Duplicates:** drop by article id, then exact lower-cased headline (keep earliest), then generic repeats (headline seen ≥ 5 times, e.g. "Corrections"). Any text in any eval set, U1 dev or a sealed pool is excluded from training.

## Steps
1. **Sealed #5 (2022–26 NYT, fresh):** the sealed #4 design (cue regex pool + random), 520 cue + 80 random, seed 7001/7002, labelled blind by Claude on U1 before any model sees it. Keep 150 at 2–3 and 150 at 0–1 (half the low side tricky). Opened once, at the end.
2. **Training pack P5 (2022–26 NYT, disjoint from step 1):** 600 headlines picked by v7e score, labelled blind on U1:
   - 400 for 2–3s: 250 with v7e 1.5–2.5 (the 2/3 and 1/2 edges), 150 above 2.5;
   - 200 for 1s: v7e 1.0–2.0 with a harm or court/aftermath cue (where 1s get called 2).
   Cost up front: about 1,200 headlines labelled inline (≈ 60k tokens), once.
3. **v7f student (teacher unchanged = v12 5-seed):** v7e recipe plus (a) teacher targets for the 2022–26 NYT news headlines (deduped) added to the distillation corpus; (b) P5 as direct labels ×3. Cuts by the same rule on U1 dev. ≈ 3 h on the MacBook.
4. **Dev gates (U1 dev, CV):** κ ≥ v7e − .01; 2–3s caught ≥ .90 of v7e's; false alarms ≤ v7e + .02; focus ≥ v6 − .02.
5. **Sealed #5, v7e vs v7f (once).** v7f replaces v7e only if: κ ≥ v7e; 2–3s caught ≥ v7e − .02; true-3 ≥ v7e − .03; **true-1 exact ≥ v7e + .10**; false alarms ≤ v7e. Otherwise v7e stays and the sealed #5 v7e numbers stand as its check on current (2022–26) news.

## After
Subject column (outlet tags → ~10 subjects, classifier trained on tags + HuffPost, tested on held-out tagged headlines), then score all archives, analysis, write-up, Differoo.
