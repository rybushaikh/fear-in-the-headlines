# PLAN v10: the five-part fear model + all fixes (frozen 23 Oct 2026, before any computing)

## Why
v9 (MPNet + weak-spot labels) cut the weak-spot error 28% (bar 30%), with no loss elsewhere. Core cause: the model judges what a headline is *about*, not what is *happening* (over / history / figurative / hedged / negated).

## The model (v10)
Encoder (MPNet; larger encoder tested as fix 9) → five part heads + fear head.
| Part | Values | Meaning |
|---|---|---|
| severity | 0–3 | worst outcome named, whether or not it is over (0 none, 1 money/minor, 2 injury/serious crime/job loss, 3 death/mass harm) |
| status | live · coming · over · history · none | is the threat still happening? |
| certainty | fact · possible · denied · question | stated as fact, hedged, negated, or asked |
| closeness | near · far · unclear | does the threat reach people like the reader (home, children, local) or is it distant? |
| literal | literal · figurative | real harm, or a figure of speech (sport, business, politics) |
Fear (0–3) = small combiner over the five parts + grammar features (+ the embedding in one arm). Each score can be explained by its parts.
Grammar features (structure first, Noesis `appraisal/`, spaCy, WordNet for unknown verbs): main verb class, negation, hedges/modals/question mark, tense and old years ("1986", "anniversary"), number of dead/injured (log scale), sport/business frame.

## The fixes, added one at a time (ablation ladder)
| Step | Fix |
|---|---|
| F0 | v9 baseline (pair training + ridge) |
| F1 | train on the score directly (regression loss + pair loss) |
| F2 | ordinal head (0<1<2<3) instead of ridge |
| F3 | minimal pairs: real twins mined from ABC + synthetic train pairs |
| F4 | five part heads; fear from parts + embedding |
| F5 | grammar features into the combiner (negation, hedges, death-toll scale, history, figurative frame) |
| F6 | calibration to the user's own ratings (isotonic, fit on half, checked on the other half) |
| F7 | average of 5 seeds |
| F8 | larger encoder (download needed; research only, the phone model stays small) |
| AL | active learning: the part-label batch is picked by v9 ensemble uncertainty (450) + 150 random; compared at equal size |
Keep rule: a step is kept only if it helps the dev score and does not worsen any gate by more than .01. One seed per step except F7.

## Labels
- Part labels: 600 real headlines (450 uncertainty-picked + 150 random), user in Cursor, codebook P1 (fear + 5 parts + reason).
- Existing: disaster 4,518 (relabels applied), everyday 1,995, weak-spot 450 (all fear; harm_fact ≈ certainty fact).
- Synthetic (below): part labels known by construction.
- Missing part labels are masked in training.

## Synthetic data (same principles as the codebook)
Minimal edits of REAL labelled headlines, each with an expected fear set by the codebook:
| T | Edit | Expected |
|---|---|---|
| T1 resolve | live threat → caught / found safe / rescued / contained | fear ≤ 1, below the original |
| T2 history | add an old year, "anniversary", "remembering" | fear ≤ 1 |
| T3 negate | "no one hurt in…", "…not linked to…" | at least 1 below the original |
| T4 hedge | "could", "may", question form | ≤ the original |
| T5 figurative | harm verb moved into a sport/business line | 0 |
| T6 scale | 2 dead → 200 dead | ≥ the original, and 3 if deaths |
| T7 closeness | local place → distant country | ≤ the local version |
| T8 counter | closure word but harm still live ("search ends, bodies found") | stays high (guards against over-correction) |
- Train and test synthetic sets use **disjoint base headlines and disjoint word fills** (verbs, places, teams, numbers), so passing the test can't be memory.
- Test suite: ~100 per edit (~800). A random 150 are checked by the user in Cursor; if agreement with the expected labels is < 90%, the generator is fixed before use.
- Scoring: direction accuracy per edit (did the score move the right way) and range accuracy (inside the expected range).

### Amendment 1 (23 Oct, agreed with the user before any training)
- **Synthetic text is written in Cursor**, not by templates (the template set came out stiff: "is it true? 36 australians missing…"). Brief: `data/eval/v10_synth_write/BRIEF.md`. Each real base headline gets the edits T1–T8 that apply; Cursor writes natural headline wording and may skip an edit that doesn't fit. Expected fear ranges still come from the table above (Cursor does not score them).
- Train bases and test bases are different headlines (v9 split); test-side edits are kept apart and never trained on. The template set is kept only as an extra check.
- The user's 150-item check is drawn from the Cursor-written test edits (≥ 90% inside the expected range, or the brief is fixed).
- **Quality weighting** of real labels: adjudicated-39 ×3, user-rated (weak-spot, parts, rough checks) ×2, relabel-checked ×1.5, AI rater ×1.
- **Three data arms**, each run on the best ladder setting and judged on the REAL sealed set only: (a) real only, (b) real + synthetic, about 1 synthetic per 3 real, (c) synthetic-heavy, about 1 synthetic per real, with synthetic pairs weighted ×2. The winner becomes v10.

### Amendment 2 (24 Oct, before training; checks done blind in Cursor)
- Synthetic check 1 (120 test edits; T1 T3 T4 T6 T7 T8): 93% inside the expected range, a PASS. Per edit: T1 91, T3 86, T4 95, T6 95, T7 90 (n=10), T8 100.
- Check 2 (30 test edits; T2 and T5 after a redo and a past-marker filter): T2 60%, T5 67%, a FAIL. The rater scores recalled deaths high ("recalls finding his wife and daughter dead" → 3), so the rule "history → ≤ 1" is itself doubtful for deaths.
- **T2 and T5 are dropped from synthetic training and from final criterion 3.** History and figurative cases are learned and judged from REAL data only: weak-spot labels, part labels, and the sealed weak-spot items.
- Synthetic training uses T1 T3 T4 T6 T7 T8 (2,356 edits); the originals are archived in `v10_private/discarded/`.

### Amendment 3 (24 Oct, after the ladder; a SECOND, separately frozen test)
- Ladder result under the original rule: all steps rejected (F1–F3 on everyday ρ; F4–F5 on weak-spot MAE; F6 no gain); winner = baseline. Reported as is.
- Found: the baseline's own seed spread (everyday ρ .728–.750 over 5 seeds) is larger than the .01 gate, and the comparison run was the high seed. So the single-seed rule cannot detect real gains.
- Re-test (dev only, sealed untouched): F3 (synthetic pairs) and F2+F3 (ordinal + synthetic pairs), 5 seeds each (0–4), averaged predictions, compared with the baseline's 5-seed average (F0 seed 0 + F7 seeds 1–4, already run).
- Same gates, ensemble against ensemble: keep if (W MAE improves ≥ .01 OR synthetic direction +1 pt) AND everyday ρ drop ≤ .01 AND disaster ρ drop ≤ .01 AND W counter MAE rise ≤ .02. If both pass, the one with the lower W MAE wins; if neither passes, the baseline wins and that is the result.
- The winner's 5-seed average is saved, and the sealed set is opened once on it vs v8.

## Test sets
- **Dev** (used to choose steps; all seen before): old weak-spot held-out 128, everyday 400, disaster 11 events, synthetic dev suite, human sets (adjudicated 39, hidden user checks).
- **Final, sealed, opened once:** fresh 150 weak-spot headlines (mined anew, none seen) + 150 fresh random ABC everyday, rated by the user; plus the sealed synthetic test suite.

## Final pass criteria (v10 vs v8 on the same items)
1. Fresh weak-spot MAE ≤ 0.70 × v8.
2. Fresh everyday fear ρ ≥ v8 − .01.
3. Synthetic suite: every edit type passes ≥ 85% direction checks, and beats v8 on each.
4. Counter-cases (T8 + real counters): MAE not worse than v8.
Later, separately: outlet checks (NYT, Guardian) ρ ≥ .70 each.
Nulls and fails are reported as they come.
